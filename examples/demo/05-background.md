## Backgrounds

`background:` takes an image (relative path or URL) or any CSS value,
for example `linear-gradient(...)` or `#123`.

- crossfades between slides
- works together with per-slide themes
- text entrances: `fade`, `slide`, `slide-left`, `zoom`, `none`

> `stagger:` delays consecutive blocks, like this list and quote.
